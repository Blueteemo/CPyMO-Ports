# CPyMO RG35XX 1.0.0 安装指南

适用于运行 GarlicOS 1.4.9 的初代 RG35XX。游戏由用户自行准备。[GarlicOS 1.4.9 发布页](https://www.patreon.com/blackseraph/posts/garlicos-for-76561333)

## 首次安装

1. 解压 ZIP，检查包内的 `SHA256SUMS.txt`。
2. 把 ZIP 中 `Roms/` 下的文件逐项复制到 TF 卡上的同名路径。保留卡上已有的 `Roms`、`APPS` 和 `Imgs` 目录及其中的其他文件。
3. 把每款游戏的完整目录放入 `Roms/APPS/CPyMO/games/`。安全弹出卡并插回设备，在 GarlicOS 的 APPS 中打开 CPyMO。
