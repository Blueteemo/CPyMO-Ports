# v0.24.5 audio7

保留16抽头、512相位，补齐连续终相位节点，取消相位511回卷到0的错误插值。普通信号保持线性；仅实际混音过满时使用左右声道联动的峰值保护（5ms保持/80ms释放），保留50%默认输出上限。无新增动态库依赖。

音频API和可选前端异步回调用短Futex互斥保护；渲染不持锁。游戏释放时先停音频再关闭借用的PAK流。异步路径不从回调写调试文件。主线程启动时写有界audio-status.txt，记录前端是否接受异步回调；同步回退继续可用。

quality.py：生产解码/重采样/混音与原安装版本的解析信号对照。thread_stress.c：并发混音、1000次播放停止、40次生命周期复位、20次主线程停顿。ASAN/UBSAN与TSAN分别编译运行。
async_core.c：真实核心异步回调和主线程同时运行，合成游戏及真实PAK资源各12次重载、108次字号切换、主线程停顿和卸载后的静音回调；私有存档目录。
real_reference.py：真实游戏9类源与4类组合，FFmpeg参考和Q16时钟/FIR延迟对齐，保留数字误差、峰值与模拟耗时证据；不代表听感。
arm_budget.py：原RG35XX目标ABI、uClibc/QEMU，交替3轮测1声道、3声道正常/过载；只是相对模拟CPU开销，不声称掌机帧率。
launcher_env.py：dash/BusyBox ash下输出音量与诊断路径导出，保护系统音量配置。

其余实际输入检查复用boot4的host/ARM开场6+6场景、hw的ARM菜单5场景、真实资源及旧档ARM8场景。Logo1/2的A跳过原本已实现，保留并复核，不重复新写跳过逻辑。
