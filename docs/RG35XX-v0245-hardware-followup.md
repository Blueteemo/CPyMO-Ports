# RG35XX v0.24.5 实机反馈修订

基础：v0.24.5 + d1a5c2d 启动器修复。音频为排查目的撤回最近的DSP与强制同步调度实验，恢复v0.24.4行为；保留50%输出增益、系统音量继承、既有音效和旧档修复。普通采样率PCM与原v0.24.4逐字节一致，仅保留分配失败及高采样率EOF非法phase保护。恢复前端支持时的可选异步回调，拒绝时仍使用帧同步后备。没有新增线程或音效优化。

游戏库脏帧先清黑底，消除透明高亮反复叠加；三行标题按实际墨迹居中。字体为小72%/默认86%/大100%，旧小档迁移为默认且大小不变。START菜单行高、基线与高亮依据墨迹边界计算。旧剧情选择布局不改。字体UI设置由UI_2迁移至UI_3，旧格式和12字节config.csav仍能读；回退旧核心需恢复rg35xx-ui.cfg备份或重新选设置。

启动器在已验证的私有内存session.cfg追加quit_on_close_content=1，使库界面B关闭内容后前端退出。RA1.14枚举1=启用，依据上游menu/menu_defines.h及retroarch.c关闭内容路径。全局RetroArch配置、独立音量和其他APP不写入。

验证方法和边界见tests/v0245_hw/README.md。真机音质、连续导航是否卡顿、实际返回GarlicOS待新包实测；不得把模拟输入、QEMU或PCM相同视为硬件验收。此前崩溃为启动器mktemp I/O失败，本修订保留其修复；用户已确认前一修复能进入游戏。
