# RG35XX v0.24.3 工程记录

基线：c82881c661aa5a1fac7f5fef9888c3f2cabb090b；v0.24.2 核心 SHA-256：8d79b85c8b962658e38007a1eade24821f851982ba01574c88d48c07e6935444。本轮从该提交建独立分支，不使用历史 build/ 对象。

## 修订

- 字体设置变更时，事务式重建当前正文页：保留页起点、脚本位置和已读标志；替换当前历史页正文，不重复添加历史；后续分页按新字号继续。失败时保留原字体及页面。92% / 100% 两档不变，每游戏 sidecar 格式不变。
- 快进模式恢复减号、值、加号，标签列和控件轴共用；值列预留所有枚举及 100% 宽度，切换时不横移。变更使用已有延迟保存。修复 R1 刚按下时越过未读对白的旁路。
- 已读 Alpha 0.85 → 0.75；未读仍为 1.0，原始 RGB 色语义保留。
- Imgs.zip 实测参照文件管理器、播放器、终端等。定稿人物图主体 239×239@(31,19) → 190×190@(60,68)，底边 258；下方说明像素保持原样。见 icon_layout.py 与 icon_metrics.json。未模拟 GarlicOS 前端裁切，实际 APPS 显示待真机。
- MP3 read-ahead EOF 不再在缓冲仍有有效尾帧时重绕；由原有 mixer 循环边界重启。17 首随包水仙1 MP3 的循环/单次解码长度一致；修复前循环均少 4608 个 44.1kHz 采样，约 104.49ms。不能据此认定数秒级提前重播已解决。
- WAV 限制到 RIFF data 块边界，防止尾部 JUNK/LIST 元数据被播放成 PCM；校验 block align 等于声道数×2。22050/44100/48000Hz 带尾块样本均验证。
- BGM 事件通过现有可关闭、有大小上限的每游戏日志输出；记录命令脚本位置、48kHz 输出时钟、解码游标、文件偏移。无新常开日志，无每帧日志。

## 未修改

50% CPyMO 总输出增益、output-volume.txt、启动器和 RetroArch 配置均沿用 v0.24.2。START/SELECT、上下方向和 L2/R2 等映射不变。未加入固定切歌淡入淡出，未修改游戏脚本/音源/字体文件或存档格式。

## 验证与限制

49 个生产编译单元以 ARM/uClibc sysroot + Clang 18/lld 18 全量 SOFTFP 编译。最终核心实际用于 QEMU；本机 sanitizer 构建只用于内存和渲染检查，未作为设备核心。测试代码在 tests/v0243，具体运行日志、配置和验收报告在工程交付包。

真实 RGB565 同文切换、重启恢复、100 次字体反复重排及页内容拼接无丢字/重字、已读策略 R1 行为、确认按钮字形对齐、65536 组 Alpha/RGB565 参考计算均验证。ASan/UBSan 通过；LeakSanitizer 因当前环境 /proc 线程枚举限制不可用，未声称泄漏检查通过。云端测试不是 RG35XX 实机验收，性能数字不当作真机 FPS。

工程材料沿用已归档 v0.24.1 SDK 与 v0.24.2 基线。本轮增量 bundle 不重复保存 SDK、游戏、字体和大二进制历史。不要把仓库中旧 research/deploy 测试二进制误当作本轮交付核心；本轮核心只以最终整合测试包及其 SHA 清单为准。
