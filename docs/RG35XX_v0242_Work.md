## 修改

- 精确四舍五入的 `/255` Alpha 合成，保留脚本 RGB；未读不透明度 1，已读 0.85，
  已读标志和“仅已读快进”继续有效。云端未复现所有未读文字发灰，不宣称已证明真机根因。
- 小字体为原字号 92%，默认；大字体保持原字号。继续使用原思源黑体 SC Medium 文件、
  输出分辨率平滑字层，不改变 hhea 1000/0。字体文件原样保留，实测 Unicode cmap 7170。
  设置写入每游戏存档位置的 `rg35xx-ui.cfg`；旧 `config.csav` 仍为六个 LE u16。
  当前句不中断，下一句按新字号重排；历史和菜单重新打开时采用新字号。
- 总输出默认 50%（约 -6.02 dB），在原混音/重采样之后做线性衰减，同时作用于
  BGM、SE、Voice，保留游戏内部三路设置；通过 `CPyMO/output-volume.txt` 持久化。
  文件仅接受 0–100 整数；异常内容回退 50，不执行文件内容。重新启动程序后生效。
- 状态提示约 25 个物理像素，放到顶部；先绘制再合成，每帧淡出，最后恢复干净底图。
  打开菜单时关闭提示；无额外输入焦点。成功、失败文本分别显示。
- 确定/取消文字通过实际非零字形包围盒确定基线，仅移动按钮内部文字，保留按钮框、
  高亮、触区和弹窗位置。三分辨率、两字号、中英文标签均检查。
- 普通游玩不输出详细 trace；错误或显式调试时，在当前游戏的实际存档目录记录
  `rg35xx.log`，每会话上限 256 KiB。`save/rg35xx-debug.flag`（或隔离存档目录中的
  同名文件）启用该游戏调试；`CPyMO/debug.flag` 启用全程序调试。
  既有 `APPS/saves/<游戏ID>/` 与 `CPYMO_SAVE_ROOT` 继续优先使用，不搬迁/删除旧存档。
- 启动器摘要固定到 `CPyMO/logs/launcher.log`，每次覆盖；RetroArch 详细输出关闭。
  CPyMO 专用 append config 禁止退出时保存全局配置，MENU 的输入屏蔽延迟设为零。
- 整合原定稿 `Imgs/CPyMO.png`，640×480 RGBA；没有生成或重绘图像。

## 按键

| 按键 | 剧情 | 菜单 / 历史 / 分支 |
| --- | --- | --- |
| A | 确认、推进 | 确认 |
| B | 按住隐藏文字 / 按界面状态返回 | 取消，沿用引擎对应界面语义 |
| X / START | 游戏操作菜单 | 不覆盖系统 MENU |
| Y | 自动播放开关 | 无快捷副作用 |
| ↑ | 历史 | 向上 |
| ↓ | 推进 | 向下 |
| ← / → | 保留原引擎语义 | 横向调节 / 导航 |
| R1 | 按住快进；遵守“仅已读”设置 | 无快捷副作用 |
| R2 | 单按保存到第 1 槽，覆盖该槽 | 无快捷副作用 |
| L2 | 单按读取第 1 槽 | 无快捷副作用 |
| SELECT | 设置 | 无快捷副作用 |
| L1 | 留空 | 留空 |
| MENU | GarlicOS / RetroArch 系统键 | GarlicOS / RetroArch 系统键 |

快存、快读只在可读正文生效；标题、隐藏状态、菜单、分支中不执行。
按住不连写；相反肩键同时按不执行，组合键消费后等所有键松开，避免伪造推进事件。
MENU 不映射到核心；专用 RetroArch 配置要求 MENU 按住时立即屏蔽游戏输入。
魔改 GarlicOS 的实际按键映射、MENU 组合键及先后松键次序必须上机确认。

## 构建和测试材料

完整基线源码、SDK 与历史保留在原交接包。v0.24.2 工程增量包含 Git bundle、patch、
本次测试源码、时间线、日志、原分辨率抓帧和报告；不再次打包 SDK 或游戏资源。
从基线 bundle 克隆后，fetch 工程增量 bundle 并 checkout 其分支，再按原
`04_构建环境与脚本/extract_sdk.sh` 解包 SDK，用 `tools/build_arm_clang_lld.sh softfp`
在全新外部 BUILD 目录编译。设置 `SDK`、`PATH`（Clang/LLD/LLVM）即可。

`tests/v0242/capture.c` 通过公开 Libretro 调用驱动原核心，时间线只模拟按键；
诊断状态使用 ELF 中 engine 的静态符号偏移只读观察，不修改被测核心。
`render_check.c` 直接包含真实合成器和弹窗绘制代码，链接其余原生对象；
`text_asan.c` 覆盖字体全部映射字符和三种落屏缩放；
`launcher_check.py` 检查专用配置、音量持久化、日志位置及全局配置和其他 APPS 不受写入。

安装包、核心 SHA、最终提交号、实际测试数与未验项目以交付报告和清单为准。
