正式候选编译禁用实验性视频，所有 #movie 成功跳过后继续原脚本；保留研究源码及历史，不要求 AVI 或修改原MP4。

所有验收脚本见 `tests/v0245/README.md`。最终安装核心、构建来源、性能/音频/布局报告和精选证据由外层交付工程提供。部署历史树含旧测试核心，不可整体覆盖TF卡。推荐安装包只更新一个明确路径的 `.so`；完整工程包含回退核心、全历史 bundle 与SDK，不分发完整第三方游戏或用户存档。
